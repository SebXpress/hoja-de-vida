# PGHV-5 Implementation Plan
> Ejecución directa en la rama existente, autorizada por el usuario. Usar executing-plans y TDD.
**Goal:** Visualizar y configurar secciones por perfil.
**Architecture:** Tabla Prisma con reglas JSON, servicio validado y endpoints protegidos. Interfaz estática del mismo origen.
**Tech Stack:** NestJS 10, Prisma 5, PostgreSQL 16, HTML/CSS/JavaScript.
**Spec:** docs/superpowers/specs/2026-11-05-pghv-5-design.md
## Global Constraints
Conservar datos, rama y secretos locales. No reset, push ni publicación.
## Review Focus
Perfil inexistente: 404. Configuración ausente: 503. Reglas inválidas: 400. Sin JWT: 401. Sin rol de gestión: 403. Recarga refleja cambios sin borrar registros. Fallo de red o sesión expirada limpia el contenido anterior.
